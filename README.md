# Sprint 6 — Автоматизация тестирования Яндекс Самокат

## Описание проекта

## Проект посвящён автоматизации тестирования веб-приложения сервиса «Яндекс Самокат» с использованием Python, Selenium WebDriver и pytest.

## Цель проекта — проверить основные пользовательские сценарии работы сайта: раздел «Вопросы о важном», навигацию по страницам и оформление заказа самоката.

## Используемые технологии

- Python

- Selenium WebDriver

- pytest

- Allure Pytest

- Allure Report

- Faker — для генерации тестовых данных

## Структура проекта

pages/ — классы страниц и методы взаимодействия с элементами сайта.

tests/ — автоматизированные тесты.

locators/ — локаторы и тестовые данные, если они вынесены в эту папку.

conftest.py — фикстуры pytest.

requirements.txt — зависимости проекта.

README.md — описание проекта.

.gitignore — файлы и папки, исключённые из Git.

Реализованные тестовые сценарии

### 1. Раздел «Вопросы о важном»

Проверка раскрытия вопросов.

Проверка текста ответов.

Проверка восьми вопросов FAQ, если все восемь тестов реализованы.

### 2. Оформление заказа

Переход к форме заказа.

Заполнение полей пользователя.

Выбор станции метро.

Выбор даты и срока аренды.

Выбор цвета самоката.

Подтверждение оформления заказа.

Проверка результата оформления и номера заказа, если этот сценарий реализован.

### 3. Навигация по логотипам

Проверка перехода на главную страницу по логотипу «Самокат».

Проверка перехода на сайт «Дзен» по логотипу "Яндекс".

Установка зависимостей

Установить зависимости проекта:

pip install -r requirements.txt 

Запуск автотестов

### Запустить тесты:

python -m pytest tests -v 

Сформировать результаты для Allure:

python -m pytest tests --alluredir=allure-results 

#### Открыть отчёт Allure:

allure serve allure-results
